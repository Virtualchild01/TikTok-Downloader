# TikTok Downloader - Android Project

Минималистичное Android-приложение для скачивания видео из TikTok без водяных знаков по ссылке.

## Ключевые особенности
1. **Скачивание без водяного знака**: получение оригинального видеопотока без логотипов TikTok.
2. **Эргономичный ввод**: поле ввода ссылки со встроенной кнопкой быстрой вставки из буфера обмена («Вставить») в одной строке.
3. **Минималистичный дизайн**: аккуратный современный интерфейс с закругленными углами всех кнопок и карточек (pill-кнопки с радиусом 24–28 dp).
4. **Тумблер темы (Авто / Тёмная / Светлая)**: удобный переключатель в нижней части экрана с сохранением выбранной темы между запусками приложения.
5. **Оригинальный логотип приложения**: готовые адаптивные и растровые иконки для всех разрешений экрана (mdpi, hdpi, xhdpi, xxhdpi, xxxhdpi).
6. **Предпросмотр видео**: обложка, никнейм автора (`@username`) и описание ролика перед скачиванием.
7. **Интеграция с системой**: сохранение напрямую в системную папку `Загрузки` через `DownloadManager` (видео сразу доступно в галерее), поддержка меню «Поделиться».

## Как собрать APK файл

### Способ 1: Автоматически в облаке через GitHub Actions (без установки Android Studio)
1. Создайте новый репозиторий на GitHub.
2. Загрузите файлы проекта (включая папку `.github`).
3. GitHub Actions автоматически соберет APK.
4. Скачайте готовый `app-debug.apk` во вкладке **Actions** в разделе **Artifacts**.

### Способ 2: В Android Studio
1. Откройте Android Studio → **File** → **Open...** → выберите папку `TikTokDownloader`.
2. Дождитесь синхронизации Gradle.
3. В меню выберите **Build** → **Build Bundle(s) / APK(s)** → **Build APK(s)**.
4. Готовый APK будет в `app/build/outputs/apk/debug/app-debug.apk`.
